🧠 引擎方法與資料品質

模型優先使用可取得的 ESPN 賽程、比分、近期比賽與球員名單／傷兵線索。預測會綜合近期得失分、主客場分拆、淨分、主場優勢及傷兵資料可用性，再以 10,000 次隨機模擬估算機率。

注意：近期得失分不等於官方 ORtg／DRtg，沒有可靠回合數資料時不會冒稱官方進攻效率、防守效率或 Pace。球員缺陣影響若無法可靠量化，也不會虛構球星扣分。公開 ESPN API 並非有服務保證的官方開發者 API，資料可能延遲或暫時無法取得。

資料：ESPN 公開賽程、球隊名單與傷兵端點。這是研究分析工具，非 ESPN 官方產品，也不保證預測準確。
